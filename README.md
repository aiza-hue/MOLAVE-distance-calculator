
# Distance Calculator

## Description
This program asks the users to input the coordinates, compute the distance using the distance formula, and display the result rounded by two decimal places.

## How to Run
1. Open the program.
2. Run the program.
3. Enter the required values.

## Input Needed
enter 
 coordinate x1 of point 1

 coordinate y2 of point 1

 coordinate x2 of point 2

 coordinate y1 of point 2



## Sample Output
```
Enter x-coordinate of point 1:2

Enter y-coordinate of point 1:3

Enter x-coordinate of point 2:7

Enter x-coordinate of point 2:8

The distance betwen the two points is 7.0710678118654755
```
